# Django Form Project 🚀

## 📌 Project Overview

This is a simple Django-based web application that demonstrates how to create and handle a form using GET and POST methods.
The project collects user details such as name, email, phone number, gender, date of birth, course, and address.

---

## 🎯 Features

* User-friendly form UI
* Handles form data using Django views
* Supports GET and POST methods
* Displays submitted data on the same page
* Clear button to reset the form
* Clean and simple design using HTML & CSS

---

## 🛠️ Technologies Used

* Python 🐍
* Django
* HTML5
* CSS3

## ⚙️ How to Run This Project

1. Clone the repository:

```
git clone https://github.com/your-username/django-form-project.git
```

2. Navigate to project folder:

```
cd django-form-project
```

3. Run server:

```
python manage.py runserver
```

4. Open browser:

```
http://127.0.0.1:8000/
```
